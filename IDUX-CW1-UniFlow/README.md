# UniFlow — ID&UX CW1 Prototype

Professional interactive prototype concept for the CO4223/CO7223 Interaction Design & User Experience Coursework 1.

## Concept
UniFlow is a student planning and wellbeing platform combining:
- adaptive dashboard
- smart calendar
- task/deadline management
- AI-assisted study planning
- focus mode
- wellbeing check-ins
- group collaboration
- progress analytics
- what-if workload simulation
- accessibility and privacy controls

## Prototype
Open `index.html` in a browser. No build step is required.

The interface is a visual medium-fidelity prototype concept intended to be refined and recreated in Figma for the final coursework submission.
