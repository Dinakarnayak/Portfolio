# Dinakar Nayak Narasimha Murthy — AI/ML Engineer & Software Developer

Personal portfolio for Dinakar Nayak Narasimha Murthy, based in Leicester, United Kingdom. The site brings together current education, experience at Next Tech AI, Wajooba and Amazon, technical skills, selected AI/ML and software projects, certifications, and professional links.

## Portfolio

The portfolio is a responsive static site built with HTML, CSS, and JavaScript. It includes a University of Leicester portrait, light and dark themes, responsive navigation, motion-reduced behavior, project links, education and experience timelines, and contact links. Profile details and links are based on the supplied CV and LinkedIn information; live follower and connection counts are intentionally omitted because they change over time.

## Run locally

Open `index.html` in a browser. No build step or package installation is needed.

## Deploy

GitHub Pages deployment is configured in [`.github/workflows/pages.yml`](.github/workflows/pages.yml). In the repository settings, choose **Settings → Pages → Build and deployment → GitHub Actions** if the Pages source has not already been configured.
